Autonomous emergency dispatchPrototype

Every caller heard. One incident.

When a crash triggers a flood of 911 calls, each caller holds a fragment of the truth. Nexus911 gives every caller their own AI agent, shares what they learn as they talk, and checks each fact before it reaches dispatch.

The problem

Big incidents arrive as many small, separate calls.

240M

911 calls reach US dispatch centers every year.

25–30%

of dispatcher positions sit vacant, so a surge of calls has nobody to go to.

3

callers can describe one crash in three ways: a child in the back seat, a witness, a driver. Today these live in separate call records.

AI is entering dispatch quickly, and language models can make things up. A hallucinated address sends responders to the wrong place. No deployed emergency AI checks what the model extracts before it is used.

How it worksAbout 20 seconds, end to end

From three calls to one dispatch package.

  1. Calls come inSeveral people call about the same emergency at once.
  2. One agent eachEach caller gets a dedicated voice agent that runs the full interview.
  3. Shared graphAgents write what they learn to one knowledge graph and read each other's findings.
  4. VerifyLayerEvery fact is checked against the caller's own words before it is stored.
  5. One incidentCalls about the same event merge by place, time and meaning.
  6. DispatchUnits are recommended with a confidence score on every fact.

Known limitations

What this prototype can't do yet.

  • It's a prototype. It has never handled real 911 callers or real dispatch systems. The demo callers are simulated.
  • Latency is a target. The 200 ms verification budget hasn't been measured under real load.
  • Roles are heuristic. Child, victim and witness detection hasn't been tested against labelled data.
  • English only. Verification and prompts assume English.
  • Memory only. Incidents and the verification cache live in memory and reset on restart.
